### Project Overview
Developed a comprehensive data security solution capable of hiding sensitive documents inside multiple media formats. The platform prioritizes high data hiding capacity while maintaining excellent visual and auditory imperceptibility.

### Key Features
* **Multi-Format Coverage:** Fully supports data embedding across text, images, audio, voice recordings, and video files.
* **Dual-Layer Security:** Implements Least Significant Bit (LSB) steganography paired with standard AES encryption routines before embedding text.
* **Modern Interface:** Built a responsive full-stack wrapper allowing seamless file uploads and instant extractions.

### Tech Stack
* **Languages:** Python, JavaScript, HTML5, CSS3
* **Libraries & Modules:** OpenCV, NumPy, Cryptography (AES core)
