### Project Overview
Built a specialized deep learning pipeline to automate the evaluation and classification of Diabetic Foot Ulcers into multiple clinical severity tiers. The system includes an interactive web interface allowing healthcare professionals to compare neural network architectures side-by-side.

### Key Engineering Features
* **Architecture Benchmarking:** Developed and evaluated five distinct modern deep learning model architectures to optimize classification accuracy and recall.
* **Multi-Class Evaluation:** Handles clinical image inputs to sort ulcer severity levels according to standardized medical classification standards.
* **Interactive Inference Deployment:** Wrapped the backend pipelines into an accessible full-stack web application for seamless image classification tests.

### Tech Stack Used
* **Backend & ML Frameworks:** Python, PyTorch / TensorFlow (Deep Learning Core)
* **Web Layer:** Flask / Streamlit wrapper frameworks
* **Data Processing Libraries:** OpenCV, NumPy, Scikit-learn
